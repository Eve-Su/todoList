## 7. 当前注意事项

### 7.1 Maven 默认 Java 环境问题

本机 `java -version` 和 `mvn -version` 当前不是同一个 JDK。

实际情况：

- `java` 指向较高版本 JDK
- `mvn` 默认运行时之前指向 `JDK 8`

当前已通过一次性命令切换 `JAVA_HOME` 到 `JDK 17` 完成构建验证，但**系统默认 Maven Java 环境未修改**。

后续开发建议：

- 开发机统一把 Maven 运行时切到 `JDK 17`

### 7.2 Spring AI 当前是占位依赖选择

当前依赖使用：

- `spring-ai-starter-model-openai`

原因：

- 需要一个可解析、可编译的具体 starter

后续如果真实模型供应商不是 OpenAI，需要替换为对应 starter。

### 7.3 当前业务逻辑仍是骨架版

目前还没有真正落这些内容：

- Agent 配置持久化
- Session 持久化
- Message 持久化
- LLM 决策
- 工具调用
- 审批挂起与恢复
- knowledge-service 实际检索接口
- job-worker 实际消费者
